# Amostras do braço de violão

As amostras `gtr_*.ogg` vêm da coleção **Meta Nylon Guitar** do repositório
[Meta Open Sound](https://github.com/facebookincubator/Meta-open-sound), mantido
pelo time Creative Audio da Meta. Os arquivos usam a camada fingerstyle e o
sample gravado para cada corda e nota, do traste aberto ao 12º traste.

Licença: **CC0 1.0 Universal**. O texto da licença está em `CC0-1.0.txt`.
Os arquivos foram convertidos para OGG para playback no app e têm seus nomes
normalizados como `gtr_<corda>_<nota><oitava>.ogg`.

Os sons do ditado rítmico (`metronome_*.wav` e `rhythm_note.wav`) foram gerados
localmente para este app; não são samples de terceiros.
